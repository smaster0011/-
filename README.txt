SubtitleMasker v1.0.0
=====================

SubtitleMasker 是一个 Windows 本地字幕遮挡小工具。
它会在屏幕上显示一条可移动、可缩放、置顶的半透明遮挡条，可用于遮挡屏幕字幕，辅助语言学习，也可用于演示时临时遮罩屏幕上的局部内容。

普通用户使用方式
----------------

1. 解压发布包。
2. 双击 SubtitleMasker.exe 启动。
3. 将遮挡条移动到需要遮挡的位置。

如果 Windows 提示“未知发布者”或 SmartScreen 警告，这是因为当前 exe 可能未进行代码签名。
请只从可信发布页面下载软件。

使用方法
--------

- 鼠标移入遮挡条时，会显示提示文字和右下角缩放手柄。
- 未锁定时，按住鼠标左键拖动遮挡条可以移动位置。
- 未锁定时，拖动右下角缩放手柄可以调整大小。
- 鼠标右键打开菜单，可调整透明度、锁定/解锁、重置位置、恢复默认设置、查看说明或退出。
- 退出时会自动保存本地配置。

快捷键
------

Esc：退出程序
Ctrl+R：重置到底部居中
Ctrl+H：切换提示文字偏好

播放器兼容性说明
----------------

如果某些播放器使用独占全屏模式，遮挡条可能无法显示在视频上方。
这属于 Windows 系统窗口层级限制。

可以尝试改用窗口化全屏、浏览器播放，或关闭播放器的独占全屏模式。

隐私说明
--------

SubtitleMasker v1.0.0 不联网、不采集数据、不读取浏览器内容、不识别屏幕内容、不保存观看记录。
软件只在本地保存窗口位置、大小、透明度、颜色、锁定状态等配置。

配置文件：
%USERPROFILE%\.subtitle_masker_config.json
