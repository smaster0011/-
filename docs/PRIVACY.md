# 隐私说明

适用版本：SubtitleMasker v1.0.0

## 简要说明

SubtitleMasker 是一个本地运行的 Windows 桌面遮挡工具。v1.0.0 不联网、不采集数据、不读取浏览器内容、不识别屏幕内容、不保存观看记录。

## 不会做什么

SubtitleMasker v1.0.0 不会：

- 自动联网检查更新。
- 上传或下载用户数据。
- 读取浏览器历史、网页内容或播放器内容。
- 截屏、录屏或识别屏幕文字。
- 保存观看记录。
- 提供、下载或传播任何影视资源。

## 本地保存什么

软件只在本地保存窗口相关配置，例如：

- 窗口位置
- 窗口大小
- 透明度
- 颜色
- 锁定状态
- 提示显示偏好

配置文件位置：

```text
%USERPROFILE%\.subtitle_masker_config.json
```

删除该文件后，软件会在下次启动时使用默认设置。

## 内容来源与合法性

SubtitleMasker 不提供、不下载、不传播任何影视资源，也不会绕过任何平台限制。用户应自行确保观看内容来源合法，并遵守影视内容平台、版权方和所在地区的相关规定。

## 未来更新

未来版本可能提供“用户主动检查更新”功能。如果加入该功能，应由用户明确触发，并在文档中说明访问的更新来源。v1.0.0 不包含该功能。
