# SubtitleMasker 更新策略

当前版本：v1.0.0

## 当前策略

SubtitleMasker v1.0.0 暂不自动联网检查更新，也不会在后台访问网络。

软件当前只在本地运行，并仅保存本地配置文件：

```text
%USERPROFILE%\.subtitle_masker_config.json
```

## 后续计划

后续版本可以增加“用户主动检查更新”功能。该功能应由用户明确点击触发，不应默认后台联网。

项目已预留 `src/subtitle_masker/update.py` 模块用于未来扩展，但 v1.0.0 不启用联网检查，不访问 GitHub API，也不下载文件。

如果未来加入检查更新功能，建议遵循：

- 默认不自动联网。
- 明确展示当前版本和可用版本。
- 只读取公开发布页面或版本清单。
- 不上传用户数据、本地配置或使用习惯。

## 更新信息来源

版本更新信息以以下内容为准：

- `CHANGELOG.md`
- 项目发布页面
- 每个发布包中的说明文档
